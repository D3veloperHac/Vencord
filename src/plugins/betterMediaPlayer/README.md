# BetterMediaPlayer

BetterMediaPlayer is an AI-assisted, enhanced version of Vencord's original `spotifyControls` plugin. It builds upon the original concept with expanded music service support, and improved media filtering. AI Used: Codex & Claude.

## Original Project

This project is based on Vencord's original `spotifyControls` plugin:

- **Original repository:** [Vencord](https://github.com/Vendicated/Vencord)
- **Original plugin:** [spotifyControls](https://github.com/Vendicated/Vencord/tree/main/src/plugins/spotifyControls)

BetterMediaPlayer is an independent modification and is not an official Vencord plugin.

## Features

- Expanded support for music services:
  - Spotify
  - YouTube Music
  - Apple Music
  - Amazon Music
  - Tidal
  - Deezer
- Filters out generic Discord listening activities and unsupported media sources.
- Improves the media player's styling and overall experience.

Actual functionality depends on the media source, system media integration, and compatibility with your current Discord and Vencord versions.

## Installation

BetterMediaPlayer is a custom plugin and is not included in the official Vencord distribution.

Follow the [Vencord custom plugin installation guide](https://docs.vencord.dev/installing/custom-plugins/) to install it. Custom plugins may require rebuilding Vencord.
